# VIK Hub - Client Onboarding & Conversation Log

This repository contains the isolated conversation log, onboarding forms, and intake templates created for **VIK Hub** / **Apex Flash Studios**.

---

## 📄 Included Files & Resources

1. **`VIK_Hub_Website_Onboarding_Form.docx`**: Word document version of the simple 1-page client onboarding intake form.
2. **`Client_Website_Onboarding_Form.docx`**: Word document version of the detailed technical specification form.
3. **`CONVERSATION_LOG.md`**: Full conversation log and transcript detailing user prompts, design choices, theme customization, and form creation.
